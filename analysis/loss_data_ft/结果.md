# 损失 / 数据对照微调：结果

Oct 16, 2026

三组都从官方 `LOL_v2_real.pth` 出发，在 LOL-v2-real 训练集上微调 2000 步（CPU，batch 8，patch 128，学习率 1e-4 余弦退火到 1e-6），裁剪、增广和 mixup 完全相同，每组只改一处：

- `l1`：官方配方继续训练（对照）
- `gan`：L1 + 条件 PatchGAN 对抗损失，权重 0.01（与 pix2pix 相同）—— 只改损失
- `bias`：训练输入先去掉用 GT 估出的逐通道暗端底座 —— 只改数据

完整数字见 `results.txt` 与 `extra_checks.txt`；对比图 `00739_compare.png`（列：GT、官方、l1、gan、bias；上行原始输入，下行去底座输入）。

## 结论

**1. 只改数据，"按亮度打折"基本消失。** 测试时不做任何校正（原始输入）：

| 模型 | 墙保持率 | 墙亮度 ×0.5 / ×1 / ×2 / ×4 / ×8 |
| --- | --- | --- |
| 官方 | 0.52 | 0.39 / 0.52 / 0.66 / 0.82 / 0.93 |
| l1@2000 | 0.54 | 0.51 / 0.54 / 0.65 / 0.79 / 0.92 |
| gan@2000 | 0.55 | 0.53 / 0.55 / 0.66 / 0.81 / 0.93 |
| bias@2000 | **0.81** | **0.71 / 0.81 / 0.85 / 0.88 / 0.91** |

曲线从"越暗打折越多"变得几乎平直，而且 1000 步（0.74）到 2000 步（0.81）还在继续上升。这是在原始输入上测的，变化来自模型学到的先验，不是因为修正了 00739 的输入。这是"数据偏置导致按亮度打折"的直接干预证据。

**2. 打折原本是在对付偏置。** 同一个 bias 模型在原始（带偏置的）测试输入上：

- 虚高单元（GT 比例 < 0.4）的输出比例 0.34 → 0.57，假颜色被保留下来
- 暗部真假分辨：单元 Spearman 0.83 → 0.71，按图 Spearman 0.84 → 0.66
- 中性区偏绿：Δa\* −0.1 → −3.2
- 00739 的墙色度回来了（b\* 21 → 29，GT 34），但色相偏绿 11.6°（GT 85.7°，输出 97.3°）

也就是说，在偏置还在的输入上，统一打折在平均意义上是合理的。训练和测试都去底座（oracle）时，bias 组中性区偏色接近 0（Δa\*/Δb\* = +0.1/+0.1），5–12 DN 的暗部比例最接近 GT（0.55/0.62，GT 0.54/0.57）。

**3. 换成 L1 + 对抗损失，没有可测的变化，但这组检验力不足。** 各项指标与 l1 组相差都在 0.03 以内。然而 gan 组相对 l1 组的输出只差 1.72 DN，比 l1 组自身两个存档之间的差（2.70 DN）还小；判别器始终没被骗过（对抗损失约 0.36）。所以这只能说明"在 pix2pix 的标准权重、2000 步内，对抗项改不动颜色行为"，不能说明"回归不是原因"。

## 对原结论的影响

- **数据导致按亮度打折：** 有了直接的干预证据。
- **回归：** 仍没有直接证据，需要更强的非回归目标才能检验。
- **00739 的墙：** 去底座训练能保住色度，但在原始输入上偏绿。实际使用需要在测试时估计偏置（不能用 GT），本实验没有做。

## 局限

- 单个种子，2000 步，patch 128。三组微调后原始 PSNR 都从官方的 22.8 降到约 20，只做组间比较。
- 去底座用 GT 估计（oracle）；0–3 DN 受量化限制，校正不了。
- 00739 的去底座输入不可靠：暗端拟合给出 R/G/B 底座 −2.6/−0.6/−0.6 DN，校正把墙的 B 从 0.1 抬到约 0.7 DN，所有模型在这个输入上墙都更灰（0.39–0.50），所以墙以原始输入的结果为准。

## 下一步

1. 更强的非回归检验：对抗权重加到 0.05–0.1 或训练更久；或者用扩散 / 流匹配目标（需要 GPU）。
2. 测试时不用 GT 估计偏置（例如用图像暗端统计），看 bias 组在真实条件下能否保住墙又不偏绿。
3. 每组补一个种子。
